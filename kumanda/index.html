Hafta sonu kumanda

Evde değilsen Cursor’u telefondan yönetmenin yolu resmi Cloud Agent yüzeyleridir. Bu sayfa onları tek yerde toplar; tarayıcıdan Cursor API anahtarı istemez.

Kurulum durumu

  • Hemen hazır: cursor.com/agents — telefon tarayıcısından ajan başlat, izle, follow-up at.
  • iPhone: Cursor iOS uygulaması (iOS 26+). Android uygulaması henüz yok; Android’de web kullan.
  • Ev PC worker: bu kurulum anında bağlı worker yoktu. Bilgisayar kapalı veya uyku modundaysa E:\ üzerindeki yerelde kalan dosyalara Cloud Agent giremez.
  • GitHub’daki projeler: Cloud Agent yalnız GitHub’a bağlı repolarda kod yazar. Public üç repo aşağıda listelenir.
  • Cursor API CORS: api.cursor.com tarayıcıdan yalnızca cursor.com kökenine izin veriyor. Bu GitHub Pages sayfası anahtar toplayıp API çağırmaz.
  • GitHub Action API yolu: PR main’e girdikten ve CURSOR_API_KEY secret eklendikten sonra çalışır.
  • E-posta SMTP: AUTH_REQUIRED — bu ortamda mail sunucusu yok. Sonuç Cursor ajanı ve GitHub PR bildirimiyle gelir.

GitHub Action ile API

Cloud Agents API v1 (POST https://api.cursor.com/v1/agents) GitHub sunucusundan çağrılır. Tarayıcıya anahtar yazılmaz.

  1. Cursor Dashboard → API Keys: kullanıcı anahtarı üret. Anahtarı sohbete yapıştırma.
  2. GitHub → bu repo → Settings → Secrets and variables → Actions: isim CURSOR_API_KEY.
  3. Bu PR main’e girdikten sonra Action sayfasından Run workflow.
  4. launch yeni ajan, followup mevcut bc-... kimliğine devam, list ajanları listeler. Repo sahibi yalnız berkyuo2-cpu olabilir.

Ev bilgisayarı (gitmeden önce)

Yalnızca PC açık, uyanık ve internette kalacaksa yereldeki projeler uzaktan yönetilir. Bu Cloud Agent ev PC’ye bağlanamaz; worker’ı sen başlatırsın.

irm 'https://cursor.com/install?win32=true' | iex
agent login
cd E:\proje-klasoru
agent worker start --name "Berk-PC"

Cursor masaüstünde Remote Control (3.9.8+): Agents ayarından aç, sohbette /remote-control yaz, sonra telefondan devam et. PC uyursa araç çağrıları durur.
